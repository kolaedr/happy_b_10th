# Квест для Жори (Minecraft-стиль)

Vite + React + TypeScript. Увесь контент (тексти, коди) — у `src/quest.ts`.

```bash
npm install
npm run dev      # локально
npm run build    # збірка в dist/
```

Деплой: пуш у `main` → GitHub Actions → GitHub Pages
(Settings → Pages → Source: GitHub Actions).
Скинути прогрес на телефоні: додай `?reset` до лінка.
